# Hướng Dẫn Thêm Hình Ảnh Blog

## 📁 Thư mục: `/client/public/images/blog/`

Để hiển thị đầy đủ hình ảnh cho các trang blog, vui lòng thêm các file hình ảnh sau:

### Danh Sách Hình Ảnh Cần Thêm:

1. **brands.jpg** (1200x800px)

   - Ảnh các logo thương hiệu nước hoa: Chanel, Dior, Versace, Gucci
   - Gợi ý: Collage các chai nước hoa cao cấp

2. **fragrance-types.jpg** (1200x800px)

   - Ảnh về các nguyên liệu nước hoa: hoa, gỗ, gia vị, cam quýt
   - Gợi ý: Hình ảnh thiên nhiên với hoa và lá

3. **how-to-choose.jpg** (1200x800px)

   - Ảnh người đang thử nước hoa hoặc nhiều chai nước hoa xếp hàng
   - Gợi ý: Styling minimalist, clean background

4. **perfume-care.jpg** (1200x800px)

   - Ảnh chai nước hoa được bảo quản đúng cách (trong tủ, tránh ánh sáng)
   - Gợi ý: Dark mood, luxury feel

5. **luxury-brands.jpg** (1200x800px)
   - Ảnh các chai nước hoa niche cao cấp: Creed, Roja, Amouage
   - Gợi ý: Gold accents, luxury packaging

## 🎨 Yêu Cầu Kỹ Thuật:

- **Kích thước**: 1200x800px (tỷ lệ 3:2)
- **Định dạng**: JPG hoặc PNG
- **Dung lượng**: < 500KB (đã optimize)
- **Chất lượng**: High resolution, sharp, professional
