## 🛠️ BƯỚC 2: XỬ LÝ ẢNH

### A. Compress (Nén File)

**Công cụ: TinyPNG.com**

```
1. Truy cập: https://tinypng.com
2. Drag & drop 5 ảnh vào
3. Đợi compress xong (tự động)
4. Download all (nút "Download all")
5. Giải nén file ZIP
```

**Kết quả:** File giảm 50-70% dung lượng, chất lượng vẫn HD

---

### B. Resize (Chỉnh Kích Thước)

**Công cụ: Canva.com**

```
1. Truy cập: https://canva.com
2. Click "Create a design" → Custom size
3. Nhập: 1200 x 800 px
4. Upload ảnh đã compress
5. Drag ảnh vào canvas, resize fit
6. Download → JPG → Quality: 85%
```

**Kết quả:** Tất cả ảnh cùng size 1200x800px

---

### C. Check Final Files

Trước khi upload, verify:

- [x] Size: 1200x800px (hoặc 1600x900px cho wide)
- [x] Format: JPG
- [x] File size: < 500KB mỗi file
- [x] Quality: HD, không bị mờ
- [x] Filename:
  - `chanel-no5.jpg`
  - `dior-sauvage.jpg`
  - `seasonal-guide.jpg`
